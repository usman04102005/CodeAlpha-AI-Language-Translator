# AI Language Translator 🌐

A Flask-based AI language translator web app with text-to-speech support.

## Features

- Multi-language translation
- Speech synthesis
- Clean responsive UI
- Flask backend API

## Technologies Used

- Python
- Flask
- HTML/CSS/JavaScript
- Googletrans

## Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Open in browser:

```bash
http://127.0.0.1:5000
```
